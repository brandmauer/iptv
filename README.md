# brandmauer/iptv — свои плейлисты и телегид

Раз в сутки GitHub Actions: скачивает плейлисты → убирает ненужное → проверяет потоки →
раскладывает по группам → собирает телегид под имена каналов → публикует на GitHub Pages.

## Добавить / удалить источник (в интерфейсе GitHub)
Actions → **manage-sources** → Run workflow → форма:
| действие | поля |
|---|---|
| `add-playlist` | `url` (обязательно), `name` (необязательно), `group` — принудительная группа, галочки: радио / проверять потоки / разрешить токены |
| `remove-playlist` | `name` **или** `url` |
| `add-delete-group` / `remove-delete-group` | `group` — точное название или `/регэксп/` |
| `list` | показать текущие источники и удаляемые группы |

Галочка «сразу запустить сборку» (по умолчанию включена) запускает build-iptv после изменения.
Те же файлы можно править руками: `config/playlists.yml`, `config/delete_groups.txt`.

## Что удаляется автоматически (config/rules.yml → exclude)
- спорт, **4K/UHD**, каналы с **часовым сдвигом** (`+1`, `+2`, `(+4)`, `МСК+2`, `UTC+3`)
- **детские**, **региональные**, **религиозные**, **магазины**, **мода**
- группы с `VPN` в названии
- ссылки с **токенами/ключами/подписью/логином** (`token=`, `wmsAuthSign=`, `s=…&e=<время>`, `user:pass@`, xtream `/live/user/pass/1.ts`, длинные ключи) — они быстро протухают.
  Исключение для источника: `allow_tokens: true`. Исключение для канала: `exclude.keep_names`.
- группы из `config/delete_groups.txt`
- каналы, недоступные из домашней сети: `config/blocked_channels.tsv` (формат = `removed_channels.tsv` из clean_playlists.py; сравнение по ссылке **без токена**, поэтому переживает смену токена). Обновляй файл после очередной локальной проверки.
- **группа целиком**, если недоступно **> 90%** её каналов (≥ 3 каналов; «недоступно» = в blocked_channels.tsv или провал проверки) → список в `dead_groups.txt`

## Качество и дубли
- Есть HD-версия канала → обычные (SD) версии удаляются (`quality.prefer_hd`).
- Из версий одного качества основная — из источника с бо́льшим приоритетом; остальные уходят в **dupes.m3u** (имя `Канал (2)`, не больше 3).

## Логика проверки потоков
- сервера GitHub в США → российские потоки часто недоступны по гео. Поэтому: ни разу не работавшая ссылка удаляется сразу, раньше работавшая — после 3 провалов подряд; если у источника упало > 60% — провалы не засчитываются; `check: false` отключает проверку источника.
- просроченный/кривой SSL-сертификат каналом-мертвецом не считается.
- Реальную проверку «из своей сети» делай локально: `clean_playlists.py` (+ `filter_groups.py`), затем залей `removed_channels.tsv` как `config/blocked_channels.tsv` и `delete_groups.txt` как `config/delete_groups.txt`.

## Включить (один раз)
1. Settings → Pages → **Source: GitHub Actions**.
2. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
3. Actions → build-iptv → Run workflow.

## Телегид
Для каждого канала (кроме радио): алиас → `tvg-id` → нормализованное имя → нечёткое (≥ 0,92; цифры и «+N» должны совпасть). Берётся первый источник EPG, где есть программа. В плейлисте и EPG `tvg-id` свой, стабильный (`pervyj-kanal`). Каналы без программы — в `unmatched_epg.txt`; добавь их в `aliases` (`config/rules.yml`).

## Защита публикации
Каналов меньше `min_total` → сборка падает, прежняя публикация остаётся. EPG не собрался → подтягивается прошлая версия. Источник недоступен → берётся снимок `state/snapshots/`.
